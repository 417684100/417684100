# Day16：Buck 闭环反馈控制与 LTspice 仿真总结

> 学习日期：2026-11-16  
> 学习主题：Buck 闭环稳压、反馈采样、PWM 调节、软启动与负载瞬态响应

## 一、今日学习目标

理解 Buck 从开环控制到闭环稳压的工作过程，并使用 LTspice 搭建教学模型，验证反馈调节、软启动和负载阶跃响应。

## 二、开环与闭环控制

### 1. 开环控制

开环控制没有检测输出电压并反馈给控制器，PWM 占空比固定。输入电压变化时，输出电压会跟着变化。

理想 Buck 关系：

Vout = D × Vin

例如输入 24V、占空比 50%，理想输出为 12V；如果输入下降到 20V、占空比仍为 50%，理想输出就变为 10V。

### 2. 闭环控制

闭环控制通过反馈分压检测输出电压，将 FB 与内部基准 VREF 比较，再由控制器调整 PWM，使输出电压趋向目标值。

典型调节方向：

- 输出偏低：FB 低于 VREF，控制器提高能量传输，通常增加 PWM 占空比。
- 输出偏高：FB 高于 VREF，控制器减少能量传输，通常降低 PWM 占空比。

实际控制器的控制极性和补偿方式要以具体芯片数据手册为准。

## 三、输出反馈分压设计

### 1. 电阻连接

- R1：VOUT 与 FB 之间。
- R2：FB 与 GND 之间。
- FB：从 R1、R2 的连接点取样。

### 2. 分压公式

VFB = Vout × R2 ÷ (R1 + R2)

已知：

- VOUT = 12V
- VFB = 0.8V
- R2 = 10kΩ

求 R1：

0.8 = 12 × 10k ÷ (R1 + 10k)

0.8 × (R1 + 10k) = 120k

R1 = 140kΩ

因此选用 R1 = 140kΩ、R2 = 10kΩ 时，12V 输出对应约 0.8V 的 FB 电压。

当 VOUT 降至 10V：

VFB = 10 × 10 ÷ (140 + 10) = 0.667V

FB 低于 0.8V，控制器应作出提高能量传输的调节。

## 四、PWM 与占空比

### 1. 公式

D = Ton ÷ T × 100%

T = 1 ÷ fs

### 2. 本次设计参数

- 输入电压：20V
- 输出目标：12V
- 开关频率：100kHz

理想占空比：

D = 12 ÷ 20 = 60%

周期：

T = 1 ÷ 100kHz = 10μs

导通时间：

Ton = 10μs × 60% = 6μs

所以理论 PWM 周期为 10μs，高电平约 6μs，低电平约 4μs。

### 3. PWM 调节链路

输出分压采样 → FB 与 VREF 比较 → 误差控制器 → PWM 调制器 → 栅极驱动 → MOSFET 开关 → 电感传输能量 → 输出电压变化。

误差放大器/控制器通常不会直接驱动功率 MOSFET 栅极，中间还需要 PWM 调制与栅极驱动环节。

## 五、Day16 LTspice 闭环 Buck 教学仿真

### 1. 功率级与反馈参数

本次沿用前一日 Buck 教学电路参数：

| 参数 | 数值 |
|---|---:|
| 输入电压（初始测试） | 24V，后改为 20V |
| 目标输出电压 | 12V |
| 开关频率 | 100kHz |
| 开关周期 | 10μs |
| 电感 | 100μH |
| 输出电容 | 100μF |
| 负载电阻 | 6Ω |
| 反馈 R1 | 140kΩ |
| 反馈 R2 | 10kΩ |
| FB 基准 | 0.8V |

### 2. 教学用控制信号

误差控制行为源：

```spice
V=limit(0.5+10*(0.8-V(FB)),0,1)
```

锯齿波：

```spice
V=mod(time,10u)/10u
```

PWM 比较器：

```spice
V=if(V(RAMP)<V(VCTRL),10,0)
```

当 RAMP 低于 VCTRL 时输出 10V，否则输出 0V。

瞬态仿真指令（跳过初始工作点）：

```spice
.tran 0 20m 0 100n uic
```

### 3. 仿真观察

- VOUT 接近 12V。
- FB 接近 0.8V。
- VCTRL 在目标工作点附近约为 0.5V（本教学比例控制器设定）。
- PWM_FB 能够产生脉冲。
- 输入由 24V 改为 20V 后，输出仍趋近 12V，PWM 占空比相应提高；测量结果与约 60% 的理论占空比相符。

### 4. 模型适用范围与限制

这是用于理解反馈关系的简化教学模型，不等同于真实电源芯片设计：

- 使用理想化电压控制开关及简化 PWM/比例控制行为源。
- 控制器没有建立真实芯片的完整补偿网络、限流、死区、驱动延迟等特性。
- 不能仅凭该模型证明真实电源的环路稳定性或硬件可靠性。
- 仿真中的启动过冲和震荡应结合模型结构分析，不能直接等同于真实产品表现。

## 六、软启动

### 1. 软启动目的

启动初期输出电压和 FB 电压接近 0，控制器可能因误差很大而要求很高占空比，导致能量传输过快和输出过冲。

软启动通过逐渐放宽控制量限制，让输出电压平缓建立，降低启动过冲和启动冲击。

### 2. 本次软启动斜坡

设置软启动时间为 5ms：

```spice
V=limit(time/5m,0,1)
```

| 时间 | SS 电压 |
|---:|---:|
| 0ms | 0V |
| 1ms | 0.2V |
| 2ms | 0.4V |
| 3ms | 0.6V |
| 4ms | 0.8V |
| 5ms 及以后 | 1V |

教学控制器将软启动信号作为控制量上限：

```spice
V=limit(min(0.5+10*(0.8-V(FB)),V(SS)),0,1)
```

仿真观察到 SS 按 5ms 斜坡上升，输出电压较之前启动过程更平缓。该实现用于教学展示软启动限幅原理，并非完整的实际芯片软启动模型。

## 七、负载瞬态响应（Load Step）

### 1. 负载变化

初始负载为 6Ω：

Iout = 12V ÷ 6Ω = 2A

并联接入第二个 6Ω 负载：

Req = (6Ω × 6Ω) ÷ (6Ω + 6Ω) = 3Ω

新的稳态负载电流：

Iout = 12V ÷ 3Ω = 4A

### 2. 负载阶跃时的物理过程

1. 负载电流需求从约 2A 突然增加到约 4A。
2. 电感电流不能瞬间改变。
3. 瞬间负载需求大于电感提供的电流。
4. 输出电容释放储能，暂时补充电流差额。
5. 输出电压短暂下降。
6. FB 检测到输出偏低，控制器增加 PWM 占空比。
7. 电感电流逐渐上升，输出电压恢复到目标附近。

关键点：负载阶跃初期由输出电容补充电流差额；电感电流随后在控制作用下逐渐变化，不能瞬间跳变。

### 3. 本次 LTspice 观察记录

- VOUT：负载接入瞬间小幅震荡，随后趋于平稳。
- VCTRL：负载接入后出现震荡，随后趋于平稳。
- PWM：占空比最高约 90%，之后逐渐衰减，约 12ms 后稳定在 63% 左右。
- 电感电流：接入瞬间峰值约 6A，随后衰减，稳态约在 3.7A～4.2A 之间。

稳态电感电流平均值估算：

IL平均 = (3.7A + 4.2A) ÷ 2 = 3.95A

与理论负载电流 4A 接近。

瞬态峰值约 6A，说明器件选型不能只按 4A 稳态电流考虑。电感需检查饱和电流、额定电流、温升及设计余量；MOSFET、二极管和输出电容也需要检查相应应力。
