## 二、核心概念

### 1. 开环与闭环控制

开环控制不检测输出电压，PWM占空比固定。输入电压发生变化时，输出电压也会随之变化。

理想Buck关系：

```text
Vout = D × Vin
```

例如：

- Vin=24V、D=50%，理想Vout=12V；
- Vin下降到20V、D仍为50%，理想Vout变为10V。

闭环控制会检测输出电压，并根据反馈误差调整PWM：

- 输出偏低：FB低于VREF，控制器提高能量传输，通常增加占空比；
- 输出偏高：FB高于VREF，控制器减少能量传输，通常降低占空比。

实际控制器的控制极性、调制方式和补偿结构应以具体芯片数据手册为准。

### 2. 输出反馈分压

反馈电阻连接：

- R1连接在VOUT与FB之间；
- R2连接在FB与GND之间；
- FB从R1和R2的连接点取样。

分压公式：

```text
VFB = Vout × R2 ÷ (R1 + R2)
```

本日设计条件：

- Vout=12V；
- VFB基准=0.8V；
- R2=10kΩ。

计算：

```text
0.8 = 12 × 10kΩ ÷ (R1 + 10kΩ)
0.8 × (R1 + 10kΩ) = 120kΩ
R1 + 10kΩ = 150kΩ
R1 = 140kΩ
```

因此选择R1=140kΩ、R2=10kΩ。

当输出下降到10V：

```text
VFB = 10 × 10 ÷ (140 + 10)
    = 0.667V
```

FB低于0.8V，控制器检测到输出偏低，并提高能量传输。

### 3. VREF、FB与误差控制器

- VREF是控制器内部基准电压；
- FB是输出电压经过分压后的采样值；
- 控制器比较FB与VREF，根据误差调整PWM控制量。

本日使用0.8V作为教学基准。输出偏低时，FB低于0.8V；输出偏高时，FB高于0.8V。

### 4. PWM周期与占空比

```text
D = Ton ÷ T × 100%
T = 1 ÷ fs
```

本日闭环仿真参数：

- Vin=20V；
- Vout目标=12V；
- fs=100kHz。

理想占空比：

```text
D = 12V ÷ 20V = 60%
```

周期：

```text
T = 1 ÷ 100kHz = 10μs
```

导通时间：

```text
Ton = 10μs × 60% = 6μs
```

所以理想情况下，PWM周期为10μs，高电平持续6μs，低电平持续4μs。

### 5. 闭环控制完整链路

```text
输出电压VOUT
    ↓
R1、R2反馈分压
    ↓
FB采样
    ↓
与内部基准VREF比较
    ↓
误差控制器
    ↓
PWM调制器
    ↓
栅极驱动
    ↓
MOSFET开关
    ↓
电感传输能量
    ↓
输出电压变化并再次反馈
```

误差控制器通常不直接驱动功率MOSFET栅极，中间还需要PWM调制和栅极驱动环节。

## 三、LTspice实验一：Buck闭环反馈仿真

### 1. 功率级参数

沿用Day15的Buck教学功率级，并将输入电压由24V改为20V进行闭环验证。

| 参数 | 数值 |
|---|---:|
| 输入电压Vin | 20V（闭环验证时） |
| 输出目标Vout | 12V |
| 开关频率 | 100kHz |
| 开关周期 | 10μs |
| 电感L1 | 100μH |
| 输出电容C1 | 100μF |
| 负载Rload | 6Ω |
| 反馈R1 | 140kΩ |
| 反馈R2 | 10kΩ |
| FB基准 | 0.8V |

功率级结构：

```text
Vin → 受控开关 → SW节点 → 电感L1 → VOUT
                       │                 │
                    续流二极管          C1、Rload
                       │                 │
                      GND               GND
```

续流二极管阴极接SW节点，阳极接GND。输出电容和负载并联在输出端。

### 2. 教学用行为源表达式

误差控制行为源：

```spice
V=limit(0.5+10*(0.8-V(FB)),0,1)
```

100kHz锯齿波：

```spice
V=mod(time,10u)/10u
```

PWM比较器：

```spice
V=if(V(RAMP)<V(VCTRL),10,0)
```

PWM_FB输出0V或10V脉冲，并用于控制电压控制开关。

### 3. 仿真设置

```spice
.tran 0 20m 0 100n uic
```

### 4. 仿真观察与结论

- PWM_FB能够稳定产生脉冲；
- FB接近0.8V时，输出接近12V；
- 将输入从24V改为20V后，输出仍趋近12V；
- 20V输入、12V输出时，测得PWM导通时间与约6μs的理论值相符，占空比约60%。

这验证了教学模型中的反馈调节方向：输入电压降低时，控制器提高占空比，以维持输出电压。

### 5. 模型限制

本次模型使用理想化电压控制开关、行为电压源和简化比例控制器，目的是理解反馈、PWM和能量传输之间的关系。它不包含真实芯片的完整补偿网络、限流、驱动延迟、死区和全部寄生参数，不能据此证明实际电源的环路稳定性或硬件可靠性。

## 四、LTspice实验二：软启动

### 1. 软启动目的

启动初期输出电压和FB通常接近0V，控制器检测到较大的输出误差。如果控制量没有限制，PWM可能在启动初期要求很高的占空比，使能量传输过快，导致输出电压过冲。

软启动通过逐渐放宽控制量限制，让输出电压平缓建立，减小启动过冲和启动冲击。

### 2. 软启动斜坡设置

软启动时间设置为5ms，行为源表达式：

```spice
V=limit(time/5m,0,1)
```

| 仿真时间 | SS电压 |
|---:|---:|
| 0ms | 0V |
| 1ms | 0.2V |
| 2ms | 0.4V |
| 3ms | 0.6V |
| 4ms | 0.8V |
| 5ms及以后 | 1V |

### 3. 控制器增加软启动限幅

```spice
V=limit(min(0.5+10*(0.8-V(FB)),V(SS)),0,1)
```

其中V(SS)限制VCTRL的最大值，SS从0V逐渐上升到1V，软启动限制逐渐放宽。

### 4. 仿真观察

- SS从0V开始线性上升，约5ms达到1V；
- VOUT启动过程比之前更平缓；
- 稳态输出接近12V。

本次验证的是教学模型中的软启动限幅原理，不代表真实芯片软启动时间、占空比斜率或启动过冲指标。

## 五、LTspice实验三：负载瞬态响应

### 1. 负载条件

初始只有一个6Ω负载：

```text
Iout = 12V ÷ 6Ω = 2A
```

在输出端并联接入第二个6Ω负载：

```text
Req = (6Ω × 6Ω) ÷ (6Ω + 6Ω)
    = 3Ω
```

新的稳态负载电流：

```text
Iout = 12V ÷ 3Ω = 4A
```

因此负载阶跃使输出电流需求从约2A增加到约4A。

### 2. 负载突然增加时的物理过程

1. 负载电流需求突然增加；
2. 电感电流不能瞬间改变；
3. 此时电感提供的电流暂时小于负载需求；
4. 输出电容释放储能，补充电流差额；
5. 输出电压短暂下降；
6. FB检测到输出偏低，控制器增加PWM占空比；
7. 电感电流逐渐增加，输出电压恢复。

关键点：负载阶跃初期由输出电容补充电流差额；电感电流随后在控制作用下逐渐变化，不能瞬间跳变。

### 3. 本次仿真记录

| 观察项目 | 实际观察 |
|---|---|
| VOUT | 负载接入瞬间小幅震荡，随后平稳 |
| VCTRL | 接入后出现震荡，随后平稳 |
| PWM占空比 | 最高约90%，之后逐渐衰减，约12ms后稳定在63%左右 |
| 电感电流 | 10ms负载接入时出现瞬态，峰值约6A；随后衰减，稳态约3.7A～4.2A |

稳态电感电流平均值估算：

```text
IL平均 = (3.7A + 4.2A) ÷ 2
       = 3.95A
```

与理论负载电流4A接近。

### 4. 工程意义

电感电流瞬态峰值约6A，高于4A稳态电流。因此器件选型不能只按照稳态电流选取。

需要检查：

- 电感饱和电流、额定电流和温升；
- MOSFET的峰值电流与导通损耗；
- 续流二极管的电流能力；
- 输出电容的纹波电流能力。

实际设计还要根据瞬态持续时间、器件降额要求和温升条件确定安全余量。

### 需要继续巩固的两个知识点

**1. 软启动为什么能减少启动过冲**

启动初期FB很低，误差较大，控制器可能要求较高占空比。软启动逐渐放宽控制量上限，避免能量传输过猛。

**2. 负载阶跃时为什么输出电容先提供电流**

负载电流需求突然增加，而电感电流不能瞬间改变。输出电容先释放电荷补充电流差额，随后电感电流逐渐增加到新的稳态值。
