# 戴维南定理学习笔记

日期：2026-11-03

## 核心结论

任何一个线性二端网络，从指定端口向外看，都可以等效为一个电压源 \(V_{\mathrm{th}}\) 与一个电阻 \(R_{\mathrm{th}}\) 串联。

这种等效只保证端口对外部电路呈现相同的电压、电流关系，不保证网络内部的电压、电流和功率相同。

## 两个等效参数

### 戴维南等效电压

先断开负载，测量或计算端口 A、B 两端的开路电压 \(V_{\mathrm{oc}}\)：

\[
V_{\mathrm{th}} = V_{\mathrm{oc}}
\]

等效电压源的正负极性必须与开路电压的极性一致。

### 戴维南等效电阻

将网络中的所有独立电源置零，再从端口向内求等效电阻：

\[
R_{\mathrm{th}} = R_{\mathrm{eq}}
\]

独立电源置零的规则：

- 理想电压源：短路；
- 理想电流源：开路。

## 求解步骤

1. 明确要分析的负载，暂时断开负载并标出端口 A、B。
2. 求端口开路电压 \(V_{\mathrm{oc}}\)，得到 \(V_{\mathrm{th}}\)。
3. 将独立电源置零。
4. 从端口 A、B 向内求等效电阻 \(R_{\mathrm{th}}\)。
5. 用 \(V_{\mathrm{th}}\) 串联 \(R_{\mathrm{th}}\) 代替原网络，再接入负载进行分析。

## 分压电路示例

一个 \(12\ \mathrm{V}\) 的电压源经过两个串联电阻供电，输出端跨接在 \(R_2\) 上：

- \(R_1 = 4\ \Omega\)
- \(R_2 = 6\ \Omega\)

输出端开路时，由电阻分压可得：

\[
V_{\mathrm{th}}
= 12 \times \frac{6}{4+6}
= 7.2\ \mathrm{V}
\]

求等效电阻时，将 \(12\ \mathrm{V}\) 电压源短路。从输出端向内看，\(R_1\) 与 \(R_2\) 并联：

\[
R_{\mathrm{th}}
= \frac{4 \times 6}{4+6}
= 2.4\ \Omega
\]

因此，原网络可等效为一个 \(7.2\ \mathrm{V}\) 电压源与一个 \(2.4\ \Omega\) 电阻串联。

## 含受控源时的处理方法

受控源属于网络结构，不能像独立电源那样置零。

先将独立电源置零，保留受控源，再在端口施加测试电压 \(V_t\) 或测试电流 \(I_t\)，计算：

\[
R_{\mathrm{th}} = \frac{V_t}{I_t}
\]

由于网络含受控源，计算出的等效电阻可能为负数。

## 适用范围

戴维南定理适用于线性二端网络，包括电阻、电容、电感、独立电源和线性受控源。

常见应用：

- 分析某个负载变化时端口电压和电流的变化；
- 简化电源、传感器和放大器输出级的等效模型；
- 研究负载匹配与最大功率传输；
- 将复杂电路化简后再使用节点法、回路法分析。

一般认为该定理不直接适用于二极管、晶体管大信号电路或开关电路等强非线性网络。

## 交流与最大功率

在交流稳态分析中，将电阻推广为复阻抗 \(Z_{\mathrm{th}}\)，得到戴维南相量模型。

对于纯电阻负载，最大功率传输发生在：

\[
R_L = R_{\mathrm{th}}
\]

此时负载可获得的功率为：

\[
P_{\max} = \frac{V_{\mathrm{th}}^2}{4R_{\mathrm{th}}}
\]

## 容易混淆的地方

- 戴维南等效是“端口等效”，不是“内部完全等效”。
- 求等效电压时必须保持原网络独立电源有效。
- 求等效电阻时才将独立电源置零。
- 含有受控源时，不能只依靠电阻串并联公式求等效电阻。
- 负载必须从原网络中完整断开，才能计算正确的开路电压。

## 一句话记忆

**开路电压定电压源，独立源置零定电阻；看端口，不看内部。**
