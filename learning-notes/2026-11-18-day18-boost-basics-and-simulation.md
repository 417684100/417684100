## 二、Boost基本结构与能量传递

Boost升压电路主要由输入电源Vin、电感L、开关MOSFET、二极管D、输出电容C和负载R组成。

### 1. MOSFET导通阶段

电流路径：

```text
Vin → 电感L → MOSFET → GND
```

- MOSFET导通，开关节点被拉低；
- 二极管反向截止；
- 输入电源向电感储能，电感电流上升；
- 输出端暂时由输出电容向负载供电。

电感电压（按电感从输入端到开关节点的方向定义）：

```text
VL = Vin
```

电感电流上升斜率：

```text
diL/dt = Vin/L
```

### 2. MOSFET关断阶段

电流路径：

```text
Vin → 电感L → 二极管D → 输出电容C / 负载R → GND
```

- MOSFET关断；
- 电感电流不能突变；
- 电感两端电压极性反转，开关节点电压上升；
- 当二极管阳极电压高于阴极约一个正向压降时，二极管导通；
- 输入电源与电感共同向输出端传递能量；
- 电感电流逐渐下降。

理想情况下，电感电压：

```text
VL = Vin - Vout
```

由于Boost正常升压时Vout大于Vin，所以该阶段电感电压为负，电感电流下降。

## 三、Boost理想升压关系与伏秒平衡

稳态周期运行时，电感一个周期内的平均电压为0，即伏秒平衡。

```text
Vin × D + (Vin - Vout) × (1-D) = 0
```

整理得到：

```text
Vout = Vin / (1-D)
```

其中：
- D：MOSFET导通占空比；
- 1-D：MOSFET关断占空比。

示例：Vin=5V、D=58.33%。

```text
Vout = 5 / (1-0.5833)
     ≈ 12V
```

**重要适用条件：** 该理想升压关系用于理想Boost的CCM稳态分析。进入DCM后，输出电压还与负载、电感量、开关频率等因素有关，不能直接把该公式当作DCM输出电压的计算结果。

本次仿真使用固定占空比PWM，没有闭环反馈自动调节，因此实际输出不保证等于12V。

## 四、Buck与Boost的对比

| 对比项目 | Buck降压 | Boost升压 |
|---|---|---|
| 电压关系（理想CCM） | Vout = D × Vin | Vout = Vin / (1-D) |
| 电感位置 | 开关节点与输出之间 | 输入端与开关节点之间 |
| 电感平均电流 | 约等于输出电流 | 约等于输入电流 |
| 输入电流 | CCM下约为D × Iout | CCM下约等于电感平均电流 |
| 输出电流 | CCM下约等于电感平均电流 | CCM下约为(1-D) × 电感平均电流 |
| MOS导通时 | 输入向电感和负载传递能量 | 输入向电感储能，输出电容供负载 |
| MOS关断时 | 电感经续流回路向负载供电 | 输入与电感经二极管向输出供电 |

需要记住：Buck和Boost的电感电流路径不同，因此不能把Buck的输入、输出电流关系直接套用到Boost。

## 五、CCM、BCM与DCM

### 1. CCM：连续导通模式

一个开关周期内，电感电流始终大于0：

```text
IL(min) > 0
```

### 2. BCM：临界导通模式

电感电流恰好下降到0，但没有持续的零电流区间：

```text
IL(min) = 0
```

### 3. DCM：断续导通模式

电感电流下降到0后，在一个周期内存在一段零电流时间：

```text
IL = 0
```

普通二极管Boost在电感电流降到0后，二极管截止，电感电流不会继续进入负值。

### 4. 负载变化对工作模式的影响

在输入电压、L、开关频率和占空比不变时，电感导通期间的电流纹波近似不变。

负载变轻（负载电阻变大）时：
- 输出负载电流需求下降；
- 电感平均电流通常下降；
- 当电感电流谷值降到0时，CCM条件不再成立；
- 电路可能进入BCM或DCM。

判断模式时，应观察实际电感电流波形，不能仅凭负载电阻大小直接下结论。

## 六、Boost电感电流纹波计算

CCM近似下，电感电流峰峰值纹波：

```text
ΔIL = Vin × D / (L × fs)
```

其中：
- Vin：输入电压，单位V；
- D：占空比；
- L：电感量，单位H；
- fs：开关频率，单位Hz。

电感电流最大值和最小值：

```text
IL(max) = IL(avg) + ΔIL/2
IL(min) = IL(avg) - ΔIL/2
```

示例：
- Vin=5V；
- L=100μH；
- fs=100kHz；
- D=50%；
- IL(avg)=300mA。

计算：

```text
ΔIL = 5 × 0.5 / (100μH × 100kHz)
     = 0.25A
     = 250mA

IL(max) = 300mA + 125mA = 425mA
IL(min) = 300mA - 125mA = 175mA
```

若计算得到IL(min)小于0，说明CCM假设不成立，不能把负值当作真实电感电流。普通二极管Boost会在电流降到0时停止导通，需要按DCM波形重新分析。

## 七、DCM三阶段与时间关系

DCM一个周期分为三个阶段：

| 阶段 | 时间范围 | MOSFET | 二极管 | 电感电流 |
|---|---|---|---|---|
| 第一阶段 | 0～D×T | 导通 | 截止 | 从0上升 |
| 第二阶段 | D×T～(D+D2)×T | 关断 | 导通 | 逐渐下降到0 |
| 第三阶段 | (D+D2)×T～T | 关断 | 截止 | 保持为0 |

定义：
- T=1/fs；
- D为MOS导通时间占周期的比例；
- D2为电感放能时间占周期的比例；
- D0=1-D-D2，为零电流时间占周期的比例。

```text
D + D2 + D0 = 1
```

DCM三角形电流波形的周期平均值：

```text
IL(avg) = 1/2 × IL(max) × (D+D2)
Iout    = 1/2 × IL(max) × D2
```

这里的平均值均按整个开关周期计算。以上关系用于理想DCM三角波分析。

## 八、LTspice Boost仿真记录

### 1. 仿真模型与参数

| 开关周期T | 10μs |

| PWM关断时间Toff | 4.167μs |
| 占空比D | 58.33% |
| 输出电容 | 基础仿真220μF；纹波实验100μF、200μF、470μF |


```spice
.model SWMOD SW(Ron=0.05 Roff=1Meg Vt=2 Vh=0)
```

```spice
.tran 0 20m 0 50n
```

```spice
.tran 0 1 0 10u
```

### 2. 48Ω与480Ω负载对比

| 项目 | 48Ω负载 | 480Ω负载 |
|---|---:|---:|
| 观察到的输出电压 | 稳态约11.2V | 稳态约17V附近（不同实验设置和测量窗口下约16.5～17V） |
| 电感电流 | 约720mA到433mA，谷值大于0 | 峰值约290mA，下降到0 |
| 工作模式 | CCM | DCM |
| 观察结论 | 电感电流连续 | 存在零电流区间 |

说明：
- 48Ω负载时，电感电流谷值大于0，符合CCM特征；
- 480Ω负载时，电感电流下降到0并维持一段时间，符合DCM特征；
- 固定占空比开环仿真不会自动把输出调节到12V；
- CCM理想公式计算出的约12V不能直接用于解释480Ω负载下的DCM输出。

### 3. DCM时间测量

480Ω负载下，用户通过波形游标测量：

| 项目 | 测量时间 | 时长 |
|---|---|---:|
| 电感放能阶段 | 6.6558～6.6581ms | 约2.3μs |
| 零电流阶段 | 6.6581～6.6600ms | 约1.9μs |
| PWM关断时间 | 理论值 | 4.167μs |

```text
D2 ≈ 2.3μs / 10μs = 23%
D0 ≈ 1.9μs / 10μs = 19%
D2 + D0 ≈ 42%
```

2.3μs+1.9μs=4.2μs，与理论关断时间4.167μs相差约33ns，属于游标读数误差范围，测量结果基本吻合。

### 4. 输出电容容量与纹波实验

实验条件：Boost输出端，负载480Ω，电容分别使用100μF、200μF、470μF。以下为用户记录的输出电压最大值与最小值。

| 输出电容 | 最大电压 | 最小电压 | 峰峰值纹波 |
|---|---:|---:|---:|
| 100μF | 16.8987V | 16.8954V | 3.3mV |
| 200μF | 16.8715V | 16.8701V | 1.4mV |
| 470μF | 16.5850V | 16.5844V | 0.6mV |

纹波计算：

```text
ΔVout = Vmax - Vmin
```

实验趋势：电容容量增加后，测得的输出纹波下降。

注意：三组测量的平均输出电压也有差异，因此不能只根据这三组数据把平均电压变化归因于电容容量。比较电容影响时，应保证除电容值外的电路、仿真时间、测量窗口和其他参数完全一致。

### 5. ESR影响输出纹波实验

保持输出电容470μF，串联ESR电阻，比较不同ESR下的纹波。

| ESR | 最大电压 | 最小电压 | 峰峰值纹波 |
|---:|---:|---:|---:|
| 0Ω | 16.5850V | 16.5844V | 0.6mV |
| 0.05Ω | 16.5927V | 16.5781V | 14.6mV |
| 0.1Ω | 16.6010V | 16.5718V | 29.2mV |
| 0.2Ω | 未实测 | 未实测 | 约58.4mV（按近似比例预测） |

0.1Ω时，700ms附近测得纹波约29.1mV；900～1000ms附近测得29.2mV，说明后一个测量窗口的纹波已基本稳定。

ESR纹波分量近似关系：

```text
ΔVESR ≈ ΔIC × ESR
```

在其他条件不变、工作状态相近时，ESR增加，ESR引起的纹波分量通常随之增加。本次0Ω、0.05Ω、0.1Ω的测量结果呈现近似比例关系。

注意：总输出纹波还受到电容充放电纹波、ESR以及波形相位关系影响，不能在所有情况下把各纹波峰峰值简单相加。

## 九、输出电容纹波的基础关系

在适用的近似条件下，Boost输出电容纹波可用下式估算（忽略ESR）：

```text
ΔVout ≈ Iout × D / (C × fs)
```

结论：
- 输出电流增加，电容需要提供的电荷增加，纹波通常增大；
- 输出电容容量增加，电容充放电引起的纹波通常减小；
- 开关频率增加，在其他条件不变时，纹波通常减小；
- ESR会引入额外的纹波电压。

该式是简化估算关系，实际纹波还要结合工作模式、波形和电容ESR判断。

## 十、容易混淆和需要记住的地方

1. Boost的MOSFET导通时，电感储能；MOSFET关断时，电感经二极管向输出释放能量。
2. 电感电流不能突变，但电感两端电压可以改变极性。
3. 二极管是否导通取决于其阳极与阴极的瞬时电压关系，不能仅凭“输出电压大于输入电压”判断。
4. CCM判断条件是电感电流谷值大于0；DCM需要实际存在零电流区间。
5. CCM公式计算出负的电感谷值，表示CCM假设失效，不代表真实电感电流会变成负值。
6. Boost的理想升压公式Vout=Vin/(1-D)不能不加判断地用于DCM。
7. 固定占空比PWM属于开环控制，输入、负载和工作模式变化时，输出电压不保证保持目标值。
8. 输出电压平均值与峰峰值纹波是两个不同指标；纹波应按Vmax-Vmin计算。
9. 电容容量和ESR都会影响输出纹波，不能只看电容量。
10. 比较仿真数据时，必须保证电路参数、仿真时间和测量窗口一致。
