## 一、暂定设计指标

| 项目 | 目标 |
|---|---:|
| 输入电压 Vin | 5V（本轮计算标称值） |
| 输出电压 Vout | 12V |
| 输出功率 Pout | 5W |
| 开关频率 fs | 100kHz |
| 输出纹波目标 | 不超过100mV |
| 效率目标 | 90% |
| 工作模式 | 优先按CCM设计 |
| 控制方式目标 | 后续实现闭环反馈 |

输出电流：

```text
Iout = Pout / Vout
     = 5W / 12V
     = 0.4167A
```

按效率90%估算输入功率和平均输入电流：

```text
Pin = Pout / η
    = 5W / 0.9
    = 5.556W

Iin(avg) = Pin / Vin
         = 5.556W / 5V
         = 1.111A
```

Boost输入端与电感串联，在没有其他输入支路时，输入瞬时电流就是电感电流，因此平均输入电流可作为电感平均电流的初步估算。

## 二、占空比与输入电压变化

理想Boost在CCM稳态下：

```text
Vout = Vin / (1-D)

D = 1 - Vin / Vout
```

输出目标固定为12V时：

| 输入电压 | 占空比计算 | 占空比 |
|---:|---|---:|
| 4.5V | 1 - 4.5/12 | 62.5% |
| 5.0V | 1 - 5/12 | 58.3% |
| 5.5V | 1 - 5.5/12 | 54.2% |

结论：
- 输出电压固定时，输入电压越低，所需占空比越大。
- 输入电压固定时，目标输出电压越高，所需占空比也越大。
- 以上为理想CCM关系；实际电路还存在二极管压降、开关压降、电感电阻等损耗。

## 三、电感纹波与电感量计算

本次先把电感峰峰值纹波设为平均输入电流的30%：

```text
ΔIL = Iin(avg) × 30%
     = 1.111A × 0.3
     ≈ 0.333A
```

Boost在CCM下的电感电流纹波近似公式：

```text
ΔIL = Vin × D / (L × fs)
```

整理得到：

```text
L = Vin × D / (ΔIL × fs)

  = 5V × 0.583 / (0.333A × 100kHz)
  ≈ 87.5μH
```

理论计算电感量约87.5μH。初步考虑标准规格和设计余量，可选用100μH作为后续设计起点。最终仍需在输入电压范围、负载范围和实际纹波要求下复核。

## 四、电感峰值电流与饱和电流

电感峰值电流近似为：

```text
IL(peak) = IL(avg) + ΔIL / 2
         = 1.111A + 0.333A / 2
         ≈ 1.278A
```

本轮练习按峰值电流增加30%作为初步饱和电流余量：

```text
Isat(min) = 1.278A × 1.3
          ≈ 1.66A
```

因此，初选时可优先寻找：
- 电感量：100μH；
- 饱和电流：至少约1.66A，优先考虑2A或更高；
- RMS额定电流：初步目标至少约1.2A；
- DCR：在满足尺寸、成本和温升约束的前提下尽量低。

注意：
1. 饱和电流与温升额定电流不是同一个指标。
2. 厂商可能按电感量下降10%、20%或其他条件定义饱和电流，必须查看数据手册测试定义。
3. RMS额定电流必须结合温升条件确认。
4. 还要考虑电感容差、温度、输入电压变化和启动/瞬态电流。

## 五、输出电容理论计算与实际选择

本次输出纹波目标为100mV。忽略ESR时，使用简化估算式：

```text
ΔVout ≈ Iout × D / (C × fs)
```

整理：

```text
C ≥ Iout × D / (ΔVout × fs)

  ≥ 0.417A × 0.583 / (0.1V × 100kHz)

  ≥ 24.31μF
```

理论最小电容约24.31μF。

本轮选择47μF作为初步设计值，而不是直接选择100μF，理由是：
- 47μF高于理论计算值，留有一定容量余量；
- 相比100μF，可能降低成本和体积；
- 仍需确认47μF在实际直流偏压、温度和容差条件下的有效电容。

实际输出纹波还包括ESR造成的分量：

```text
ΔVESR ≈ ΔIC × ESR
```

所以不能只凭标称电容量判断纹波是否达标。还要检查电容纹波电流额定值、ESR、耐压、温度和有效电容量。100mV目标需要在完整仿真和实测中验证。

## 六、MOSFET耐压初选

Boost中MOSFET关断时，开关节点电压通常接近输出电压，但实际还会受到寄生电感、二极管反向恢复和布局振铃等因素影响。

本轮按输出电压的1.5倍作初步耐压余量：

```text
VDS(rated) ≥ 12V × 1.5 = 18V
```

18V是本轮计算得到的初步下限，不代表18V或20V器件在实际电路中一定安全。20V器件的余量可能不足；可先把30V或40V器件作为候选范围，再根据实际开关尖峰、输入瞬态和降额要求确认。

MOSFET选型不能只看耐压，还要检查：
- RDS(on)及其对应的栅极驱动电压；
- 导通损耗和开关损耗；
- 栅极电荷Qg；
- 热阻、封装和结温；
- SOA及脉冲电流能力；
- 实际VDS尖峰和布局寄生参数。

## 八、本次学习结论

本次完成了Boost完整设计流程的前半段，能够从设计指标逐步推导关键器件参数：

1. 由输出功率和电压计算输出电流；
2. 把效率目标纳入输入功率和平均输入电流估算；
3. 根据输入、输出电压计算理想占空比，并判断输入电压变化的影响；
4. 根据电感纹波比例计算电感量；
5. 根据电感平均电流和纹波计算峰值电流；
6. 根据峰值电流和预留余量初选电感饱和电流；
7. 根据输出纹波目标估算理论最小电容，并考虑ESR和有效电容；
8. 根据输出电压和初步余量估算MOSFET耐压下限。
