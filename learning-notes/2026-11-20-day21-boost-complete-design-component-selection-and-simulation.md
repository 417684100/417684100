- 本日定位：继续 Day19 的 Boost 完整设计与优化，完成关键器件参数推导、器件初选、故障分析，并检查现有 LTspice 开环仿真。

## 一、设计指标与功率计算

| 项目 | 数值 |
|---|---:|
| 输入电压 Vin | 5V |
| 目标输出电压 Vout | 12V |
| 输出电流 Iout | 2A |
| 输出功率 Pout | 24W |
| 开关频率 fs | 100kHz |
| 预估效率 η | 90% |
| 电感纹波系数 | 30% |

输出功率：

```text
Pout = Vout × Iout
     = 12V × 2A
     = 24W
```

按90%效率估算输入功率：

```text
Pin = Pout / η
    = 24W / 0.9
    ≈ 26.67W
```

输入平均电流：

```text
Iin(avg) = Pin / Vin
         = 26.67W / 5V
         ≈ 5.33A
```

Boost 输入端与电感串联，在没有其他输入支路时，输入平均电流可近似看作电感平均电流：

```text
IL(avg) ≈ 5.33A
```

设计顺序必须先明确输出功率，再计算输入功率和输入电流，之后才能进行电感、开关器件和电容的选型，不能先随意选器件再期待它满足功率要求。

## 二、占空比计算

理想 Boost 在 CCM 稳态下：

```text
Vout = Vin / (1 - D)

D = 1 - Vin / Vout
  = 1 - 5 / 12
  ≈ 0.5833
  = 58.33%
```

结论：
- 输入电压越低，为达到相同输出电压，所需占空比越大。
- 该关系是理想 CCM 关系；实际输出还会受到二极管正向压降、MOSFET 导通压降、电感 DCR 等损耗影响。
- 实际电路的占空比和输出电压不能只用理想公式判断，必须结合器件压降和波形验证。

## 三、电感计算与初选

本日按电感电流纹波为平均电感电流的30%进行设计：

```text
ΔIL = IL(avg) × 30%
     = 5.33A × 0.3
     ≈ 1.60A（峰峰值）
```

Boost 电感电流纹波近似公式：

```text
ΔIL = Vin × D / (L × fs)

L = Vin × D / (ΔIL × fs)
  = 5V × 0.5833 / (1.60A × 100kHz)
  ≈ 18.23μH
```

理论电感量约18.23μH，初步选择标准值22μH。

电感峰值电流：

```text
IL(peak) = IL(avg) + ΔIL / 2
         = 5.33A + 1.60A / 2
         ≈ 6.13A
```

电感 RMS 电流近似估算（假设电感电流纹波为三角波）：

```text
IL(rms) ≈ sqrt(IL(avg)^2 + ΔIL^2 / 12)
        ≈ sqrt(5.33^2 + 1.60^2 / 12)
        ≈ 5.35A
```

初步电感选型方向：

| 参数 | 初步要求/结果 |
|---|---:|
| 电感量 | 22μH |
| 平均电流 | 约5.33A |
| RMS 电流 | 约5.35A |
| 峰值电流 | 约6.13A |
| 饱和电流 | 应高于峰值并留足瞬态余量；练习候选约10A |
| RMS 额定电流 | 练习候选约6A，需核实温升条件 |

注意：
1. Isat 与 Irms 不是同一个参数，不能互相替代。
2. 电感饱和电流必须查看厂商的定义，例如电感量下降10%或20%时的电流。
3. RMS 额定电流取决于温升条件、封装、PCB 铜面积和散热环境。
4. 22μH、10A Isat、6A Irms 只是初步候选，不能在没有数据手册和热验证时认定最终合格。

## 四、输出电容计算与选择

输出电容纹波的简化估算（暂时忽略 ESR）：

```text
ΔVC ≈ Iout × D / (C × fs)

C ≥ Iout × D / (ΔVC × fs)
```

以100mV电容纹波目标估算：

```text
C ≥ 2A × 0.5833 / (0.1V × 100kHz)
  ≈ 116.6μF
```

因此理论容量约116.6μF。实际纹波还包含 ESR 造成的分量：

```text
ΔVESR ≈ ΔIC × ESR
```

本日比较过以下候选电容：

| 方案 | 容量 | ESR | 耐压 |
|---|---:|---:|---:|
| A | 150μF | 40mΩ | 16V |
| B | 220μF | 15mΩ | 25V |
| C | 330μF | 60mΩ | 25V |

选择 B（220μF、15mΩ、25V）作为更合适的初步候选，理由：
- 容量高于理论估算值，有一定余量；
- ESR 较低，有利于减小 ESR 纹波；
- 25V 耐压相对12V输出保留了更好的电压余量。

不能只看标称容量，还必须核对直流偏压下的有效容量、纹波电流额定值、ESR 随频率和温度的变化、耐压降额及寿命。

## 五、MOSFET 初步选型与损耗

### 1. 耐压

Boost MOSFET 关断时承受的电压通常接近输出电压，但寄生电感、开关速度、二极管反向恢复和 PCB 布局会产生尖峰。

本日比较过15V、20V、30V耐压档位。20V 不能仅凭“高于12V”就判定安全；在没有测得 VDS 尖峰前，应优先考虑更充足的耐压候选，并最终依据实际尖峰和数据手册降额要求确认。耐压越高也不一定越好，还要兼顾 RDS(on)、Qg、成本和开关性能。

### 2. 电流额定值

本日比较5A、8A、15A的额定电流选项，选择15A作为初步候选，原因是电感峰值电流约6.13A，8A档位余量较小。

注意：数据手册的最大漏极电流往往基于特定壳温或脉冲条件，不等于实际电路可长期承受的电流。必须同时检查 SOA、RDS(on)、封装、热阻、PCB 散热和结温。

### 3. 导通电阻

比较10mΩ、20mΩ、40mΩ，选择10mΩ有利于降低导通损耗。

用电感平均电流作简化估算：

```text
Pcond ≈ IL(rms)^2 × RDS(on) × D
```

若暂时忽略占空比影响，仅用5.33A估算电流平方乘电阻：

| RDS(on) | 简化 I²R 估算 |
|---:|---:|
| 10mΩ | 0.284W |
| 20mΩ | 0.568W |
| 40mΩ | 1.136W |

这只是便于比较电阻大小的粗略估算，不是完整 MOSFET 导通损耗。实际应按 MOSFET 导通期间的电流 RMS、占空比以及高温下 RDS(on) 计算。

### 4. 栅极电荷与驱动损耗

栅极驱动功率近似：

```text
Pgate = Qg × Vdrive × fs
```

按驱动电压10V、频率100kHz比较：

| 方案 | Qg | 栅极驱动功率 |
|---|---:|---:|
| A | 40nC | 40mW |
| B | 15nC | 15mW |

低 Qg 通常有利于减小驱动损耗，并可能降低开关过程的负担。但 Pgate 是驱动电源提供的栅极充放电功率，不等于 MOSFET 全部开关损耗。还要考虑驱动电阻、驱动器能力、开关速度、米勒平台和 EMI。

## 六、Boost 二极管选型

Boost 二极管需要检查：
- 反向耐压 VRRM：应高于实际承受的反向电压，并考虑尖峰和降额；
- 平均正向电流 IF(AV)：Boost 输出端二极管平均电流近似等于输出电流；
- 峰值/脉冲电流：应覆盖电感峰值及瞬态，检查数据手册脉冲条件；
- 正向压降 VF：影响导通损耗；
- 反向恢复特性：恢复电荷和恢复时间会影响 MOSFET 开通时的尖峰和损耗；
- 热阻、封装和散热条件。

平均电流初步估算：

```text
ID(avg) ≈ Iout = 2A
```

峰值电流近似接近电感峰值：

```text
ID(peak) ≈ IL(peak) ≈ 6.13A
```

本日比较的候选方案：

| 方案 | 反向耐压 | 平均电流档位 | 正向压降 | 反向恢复 |
|---|---:|---:|---:|---|
| A | 30V | 3A | 0.5V | 相对较差 |
| B | 40V | 5A | 0.35V | 相对较好 |

初步选择 B 更合理：耐压、电流档位和正向压降都有更充足的余量。仍需核对具体器件在实际电流和温度下的 VF、反向恢复参数及热性能。

二极管导通损耗的粗略估算：

```text
Pdiode ≈ VF × ID(avg)
```

若 VF=0.35V：

```text
Pdiode ≈ 0.35V × 2A = 0.7W
```

若 VF=0.5V：

```text
Pdiode ≈ 0.5V × 2A = 1.0W
```

反向恢复电流越大，MOSFET 开通瞬间的电流尖峰和损耗通常越大，因此应关注二极管的反向恢复特性。

## 七、损耗与器件选择之间的权衡

| 优化方向 | 主要影响 | 注意事项 |
|---|---|---|
| 降低 MOSFET RDS(on) | 降低导通损耗 | 低 RDS(on) 可能伴随更大芯片面积或 Qg |
| 降低 MOSFET Qg | 降低栅极驱动负担，改善开关驱动需求 | 仍需检查开关速度、EMI 和实际开关损耗 |
| 降低二极管 VF | 降低二极管导通损耗 | 同时检查耐压、反向恢复和热性能 |
| 降低二极管反向恢复电荷 | 减小 MOSFET 开通尖峰及相关损耗 | 依据具体器件和工作条件比较 |
| 降低开关频率 | 通常可降低开关损耗 | 电感、电容可能需要增大，纹波和动态响应也会变化 |
| 降低电容 ESR | 降低 ESR 纹波和损耗 | 还需核对纹波电流、容量和寿命 |

不能只追求某一个参数最小。器件选型是耐压、电流、损耗、热、体积、成本和可靠性的综合权衡。

## 八、故障路径分析

### 1. MOSFET 短路

MOSFET 永久短路后，输入端可能形成：

```text
输入正极 → 电感 → 短路的 MOSFET → GND → 输入负极
```

这会形成较大的输入电流，可能导致电感过流、器件发热或损坏。输出电容原有储能仍可能短时向负载供电并逐渐放电；Boost 二极管通常会因输出端电压而处于反向偏置状态。不能简单地把故障输出电压说成 Vin−VD。

### 2. 二极管短路

二极管短路后，Boost 升压功能失效。MOSFET 关断时，输入可经电感和短路二极管向输出传递能量，输出电压趋向输入电压附近；MOSFET 导通时，输出电容还可能经短路二极管和 MOSFET 形成放电故障路径。具体电流大小取决于输入源阻抗、线路阻抗和保护动作。

### 3. 保护措施

- 输入保险丝或电子限流；
- MOSFET 过流保护 OCP；
- 输出过压保护 OVP；
- 电感饱和电流和器件脉冲能力留有余量；
- 必要时增加输入/输出故障隔离设计。

OVP 不能单独解决输入到输出的直通故障，保护方案必须结合具体故障路径设计。

## 九、LTspice 开环 Boost 仿真检查

本日重新检查了此前的 Boost 基础仿真。需要明确：当前这个仿真电路没有闭环反馈分压和反馈控制器，属于开环 PWM 驱动的 Boost 基础电路。电路中有二极管、输出电容和负载电阻等功率级器件，但没有 FB 反馈节点，因此不能测量或分析 FB 电压，也不能把输出电压偏离12V直接判定为反馈异常。

本日测得输出平均值：

```text
AVG(V(VOUT)) = 11.2080424516
FROM 0.015 TO 0.02
```

即测量窗口15ms至20ms内，输出平均电压约为11.208V。

与12V理想目标的差值：

```text
12V - 11.208V ≈ 0.792V
```

这个结果在开环仿真中不能单凭数值认定为故障。实际输出低于理想计算值，可能与二极管正向压降、MOSFET 导通压降、电感 DCR、负载和实际占空比有关。二极管压降是需要核对的因素之一。

后续仿真检查应按顺序进行：
1. 核实 PWM 实际占空比和栅极波形；
2. 测量二极管导通时的正向压降；
3. 检查电感电流波形及是否进入饱和或 DCM；
4. 检查输出电压纹波和稳态区间；
5. 若后续增加反馈控制器，再建立 FB 分压、补偿和闭环调节分析。

当前仿真结论：已获得输出平均电压11.208V；尚未完成二极管压降、PWM 实际占空比及完整稳态波形核对。没有反馈节点，不应虚构 FB 测量结果。

## 十一、容易混淆的知识点

1. 输出功率必须先确定，才能正确推导输入电流和器件应力。
2. 电感峰值电流、平均电流和 RMS 电流是不同指标。
3. 电感 Isat 与 Irms 不能混为一谈。
4. MOSFET 数据手册最大电流不等于实际可持续工作电流。
5. 栅极驱动功率不等于 MOSFET 全部开关损耗。
6. 二极管平均电流和峰值电流必须分别核对，不能拿峰值电流直接替代平均额定电流。
7. 二极管压降会影响实际 Boost 输出电压和效率。
8. 开环 Boost 没有 FB 节点，不能按闭环电路的方法测量反馈电压。
9. 理想 Boost 公式用于初步计算，最终必须结合器件压降、寄生参数和仿真/实测。
10. 器件初选不等于最终选型，必须查看具体数据手册并完成热和应力验证。
